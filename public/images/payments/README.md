# Payment logo sources

These assets are used only to identify payment methods available through Jèko Checkout.

- `wave-mobile-money.png`: Wave official website, https://www.wave.com/img/nav-logo.png
- `orange-money.svg`: Wikimedia Commons file `Logo Orange Money.svg`, source Orange Cote d'Ivoire.
- `mtn-momo.svg`: MTN MoMo Developer Portal, https://momodeveloper.mtn.com/content/mtnmomoLogo.svg
- `moov-money-flooz.png`: Wikimedia Commons file `Moov Money Flooz.png`, credited to Moov Africa Togo.

Djamo is rendered as a compact typographic mark in the payment-method component
to avoid loading a remote logo during checkout. Its official wordmark was
visually checked against https://www.djamo.com/images/partners/djamo.png.

The logos remain trademarks of their respective owners.
